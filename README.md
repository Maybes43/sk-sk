# Slovenský zošit

Тренажёр словацкого языка: слова и фразы по урокам и темам, интервальные повторения, спряжение глаголов, озвучка голосом устройства. Работает в браузере и устанавливается на телефон как приложение, без интернета тоже работает.

## Как выложить на GitHub Pages

1. Создай на GitHub новый **публичный** репозиторий, например `zosit`. На бесплатном аккаунте Pages работает только для публичных репозиториев.
2. Загрузи в него все файлы из этой папки, включая скрытый `.nojekyll`:
   - через сайт: **Add file → Upload files**, перетащи содержимое папки;
   - или из терминала:
     ```bash
     git init && git add . && git commit -m "Slovenský zošit"
     git branch -M main
     git remote add origin https://github.com/<логин>/zosit.git
     git push -u origin main
     ```
3. В репозитории открой **Settings → Pages**, в разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту-две сайт появится по адресу `https://<логин>.github.io/zosit/`. Ссылка видна там же, в Settings → Pages.

## Установка на телефон

- **iPhone (Safari):** открыть сайт → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** открыть сайт → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

После установки приложение открывается с главного экрана и работает без интернета.

## Где хранится прогресс

Прогресс хранится только на устройстве, в браузере. Сервера и регистрации нет, у каждого ученика свой прогресс на своём телефоне.

- Чтобы перенести прогресс на другое устройство: **Прогресс → Данные → Скачать резервную копию**, затем на новом устройстве **Загрузить из файла**.
- На iPhone лучше установить приложение на экран «Домой». Если открывать сайт просто во вкладке Safari и долго им не пользоваться, Safari может удалить его данные.

## Озвучка

Используется встроенный синтез речи устройства. Кнопки прослушивания появляются, только если на устройстве установлен словацкий голос. Если его нет, во вкладке «Прогресс → Озвучка» написано, где его добавить.

## Обновление

Замени `index.html` и `sw.js` новыми файлами из сборки и сделай push. Версия кэша в `sw.js` меняется с каждой сборкой, поэтому у пользователей обновление подтянется при следующем открытии.

## Источники

Частоты слов взяты из набора данных [wordfreq](https://github.com/rspeer/wordfreq) (Robyn Speer и др.), лицензия CC BY-SA 4.0. Слова приведены к словарной форме с помощью [simplemma](https://github.com/adbar/simplemma). Тематические наборы и переводы составлены для этого приложения. Сомнительные формы стоит сверить по словарю [slovnik.juls.savba.sk](https://slovnik.juls.savba.sk).
